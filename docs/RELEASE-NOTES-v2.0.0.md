# Meme 雷达开源版 v2.0.0

V2 动态雷达升级：画面更有科技感，观察线索更直观，继续按免费 AVE API 额度设计。

## 更新内容

- 新增动态雷达：中心光核、伸缩触手和游动节点。无名点仅作装饰，真实候选显示名称并保持连线；装饰不计数、不触发提醒。
- 保留中文 / English 语音组件与合格提醒置顶样式；当前未核验线索不触发自动推荐提醒，可手动试听。
- 保留动态视图开关及系统减少动态效果适配，不增加 AVE 请求。
- 默认打开 BSC，统一 BSC 链名称。
- 页面状态请求串行执行，失败退避；行情补全按批轮换。
- 统一旧 macOS 启动入口的后台守护行为，限制退出等待时间，避免连接未结束导致重启卡住。
- 首页保持简洁，不新增故障日志或复杂诊断面板。

## 测试与安装

待核验线索正常展示并标注“初筛 · 未核验”，已知风险仍按现有规则过滤。尚未接入可靠的 AVE 收录状态及关联持仓风险证据，当前自动候选推荐提醒暂不触发（包括语音、置顶和桌面新币通知），历史推荐缓存不能补位。扫描与动画保留，连接问题显示简短说明而非内部错误代码。这不代表已实现气泡图风险自动识别。

已通过自动化回归、隔离首次配置及崩溃恢复测试，并做了 macOS Chrome 动画和布局实测。Windows 包已做结构与安全校验，等待 Windows 真机验收；Safari 尚未实测，不承诺所有设备均达到相同帧率。

Windows 测试请完整解压到新文件夹，启动 `MemeRadar-OpenSource.exe` 并保留启动窗口。升级前备份旧版和本机配置，勿公开 `state/`、日志或 API Key。

使用与配置教程见 X [@bi_9527zx](https://x.com/bi_9527zx) 置顶。

本工具仅提供行情观察线索，不构成安全或收益保证，不连接钱包、不签名、不自动下单。免费 API 限频与网络故障仍可能发生。
