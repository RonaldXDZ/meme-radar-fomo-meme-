# Meme 雷达开源版 v0.1.11

这次重点打磨免费 API 下的日常使用：界面更简洁，候选时间更清楚，连接与启动更稳健。

## 本次更新

- **候选统一展示**：移除首页历史事件、表现验证面板，保留扫币需要的信息。
- **新鲜线索优先**：旧线索不再挤到新鲜候选前面；到期卡片自动移除，断线也不会无限保留。
- **时间分清楚**：分别显示首次入选和行情更新时间，不把老币刷新当成新发现。
- **提醒更省心**：支持中文 / English 手动切换、跨标签去重；实际播报的有效候选置顶高亮。
- **多链状态清楚**：BSC、Solana、Base、以太坊和 Robinhood 提供切换入口，按钮标明是否加入轮询；最多选择三条链共享额度。
- **连接与行情补充优化**：慢补充请求转到后台，修复误报本地离线；受支持链批量补充行情，不额外消耗 AVE CU。
- **免费额度保护**：共享请求队列、分页轮换和限频退避，重启保留额度账本，不靠反复请求或放宽过滤凑候选。
- **安装更轻量**：清理旧数据源客户端、配置接口及运行依赖，改进启动守护和旧版资料迁移。
- **快捷入口保留**：详细行情一键打开对应 AVE 页面；“下载最新版”直达本仓库最新下载页。

## 下载与升级

下载下方对应系统的 ZIP，完整解压后启动。Windows x64 包附带运行环境；macOS 首次启动会检查运行环境。

“下载最新版”是下载页入口，**不会自动覆盖安装**。升级请先关闭旧版，保留旧目录备份，将新版解压到新目录；需要保留 Key、额度账本和设置时，按 [README 的迁移步骤](https://github.com/nhovongoc0-max/meme-radar#下载最新版) 操作。不要将本机 `state/`、日志或 API Key 上传到公开仓库。

免费模式全局每 5 分钟最多请求一条链，多链轮询会分摊更新频率；上游限频时自动延后。不是全链实时推送，也不承诺永不限流。

本版已通过自动化测试和 macOS 本地验证；Windows 便携包已做结构与文件校验，尚未完成本版 Windows 真机验收。

使用与配置教程请查看 X [@bi_9527zx](https://x.com/bi_9527zx) 的置顶内容。
