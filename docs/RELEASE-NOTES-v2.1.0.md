# Meme 雷达开源版 v2.1.0

本次重点修复空列表、旧版误启动与断线恢复，保留 V2 动态触手和游动节点效果。

- 新安装默认查看并扫描 BSC，避免页面与后台扫描链不一致；升级保留已有轮询设置，未启用链提供简短启用提示。
- 首屏和切链立即读取已有候选缓存，减少空白等待；修复语音状态首次加载时序和页面样式安全策略报错，不额外请求 AVE。
- 修复超过 6 小时的活跃代币因缺少默认不请求的历史资料而整批被拦的问题。行情初筛通过可作为“初筛 · 未核验”观察线索展示；已知貔貅、刷量、卖出限制、税费异常等风险仍拦截，过期行情不会伪装成实时数据。
- 请求超时主动取消未结束的响应；物理请求长期卡住时，后台守护恢复本机服务。限流等待不会被误判为卡死，也不会清空本机用量账本。
- 启动检查核对实际运行版本，防止新安装包误用同目录旧进程。版本不一致会提示先关闭旧版，不自动覆盖本机资料。
- 语音区域如实显示可用状态：严格模式缺少安全核验证据时仅可试听，不再显示已开启自动提醒。
- 清理旧版说明中的旧数据源名称；保留防止历史凭证被打包或回传的安全检查。

继续按免费 AVE API 设计：共用全局请求队列，正常每 5 分钟最多一次 AVE 热榜请求，多链轮询；遇到限流自动退避。新版本不额外增加逐币付费查询。

**当前限制：** 免费快速模式尚无可靠的 AVE 收录状态、关联持仓风险证据接入，自动安全推荐、语音候选播报和推荐置顶仍保持关闭；仅展示未核验观察线索。不宣称能识别所有诈骗盘或保证收益。

Windows 请完整解压到新文件夹，运行 `MemeRadar-OpenSource.exe`；macOS 运行 `安装并启动.command`。升级前关闭旧版并备份本机资料。顶部“下载最新版”直达官方发布页，不自动覆盖配置。

使用与配置教程见 X [@bi_9527zx](https://x.com/bi_9527zx) 置顶。请勿公开 API Key、`state/` 或日志。

已提供 Windows x64 和 macOS 包；Windows 真机及 Safari 仍需实际设备验收，不承诺所有设备表现一致。
